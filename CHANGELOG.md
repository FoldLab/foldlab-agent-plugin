# Changelog

Notable changes to the FoldLab Agent Plugin are recorded here. This project follows semantic versioning for its plugin package; before `1.0.0`, compatibility expectations would be more limited.

## 1.0.0 — 2026-09-24

- Initial public release with `fold-spec` and `fold-viewer` skills.
- Add portable plugin metadata and thin Codex and Claude Code manifests/catalogs.
- Document installation, version boundaries, manual evaluation cases, contribution, and future direction.
- Keep v1 documentation-only: no scripts, validation server, MCP service, or npm distribution.
